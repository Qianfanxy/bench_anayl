"""
帮忙做一个极简天气App的移动端UI，画布用iPhone 15 Pro，面向每天要判断穿衣出行的通勤上班族，产品就一个定位：只回答今天该穿什么，别整一堆气象数据糊用户脸上。结构是顶部区+内容区+底部导航（3个tab）。整体走插画风，配一套统一风格的小插画或角色形象来撑气氛，背景能随晴、雨、夜等天气状态变化，插画和文字排版、配色要融在一起别显得贴纸感太重。版式还是用Bento Grid，但这版把内容拆成一张张卡片顺着往下流，大小不一的格子拼接，核心的温度和建议给最大格子。信息节奏做得紧凑高效点，卡片之间挨得近一些，让用户扫一眼就能快速抓到重点，别拖泥带水。形状上统一走柔和的大圆角，卡片、按钮、标签的边角都圆润一点，整体看着亲和不生硬，按钮和标签统一用胶囊形状。分区上用分组标题+区块的方式浏览，整体栅格保持均匀稳定的节奏，别东一块西一块乱跳。

一共做3个页面：
1、今日天气页（一级入口页）：顶部显示当前城市名+切换入口。核心区一块大格子放大字号当前温度和一条生活化建议文案（比如"有点凉，建议加件外套"），可以带体感温度和天气状况描述。下面用卡片流形式一张张往下排空气质量、24小时天气横滑（一定要能横向滑动看逐时变化）、未来多日预报列表，每个分区有个小标题带着，卡片排布紧凑一点、圆角柔和一点。另外要做一个定位失败态：定位不到城市时页面上要有清晰提示和手动选城市的引导，别让用户干瞪眼。
2、城市管理页（二级页面）：顶部左上角放返回今日天气页的按钮。主体是已添加城市的卡片流列表，每个城市卡片要带当前天气概况（图标+温度），大圆角、间距紧凑，风格要跟首页统一。要有搜索城市的入口、添加城市按钮，支持删除和把定位城市置顶，排序逻辑自己定，胶囊按钮用在筛选或者操作项上。
3、设置页（二级页面）：顶部同样有返回按钮回到今日天气页。内容用分组卡片流展示，温度单位切换（摄氏/华氏）和通知提醒开关各占独立一行，用分区标题隔开，比如"通用""通知"这种分组。可以补每日提醒时间设置、天气预警推送开关、关于与反馈入口，每一项都做成独立列表行，圆角柔和，配上小图标。
3个页面要能互相到达，别出现进不去的死页面，每个二级页面返回入口要清楚明确。

图标自己画或用开放图标库，别用 emoji；不要引用外部图片链接，需要配图的地方用色块或简单图形占位。文案写真实中文内容，不要 Lorem Ipsum。字号、颜色、间距保持一套统一规范即可，不用铺开做完整设计系统。
"""
