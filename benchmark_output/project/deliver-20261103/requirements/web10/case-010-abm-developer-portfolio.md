## 00 · Start Here 设计任务

LEVEL L2 · DESIGN TASK · v2

ABM — developer portfolio

Design a one-page portfolio for a full-stack software engineer: who they are, the tech they use, two projects, work experience and contact. Desktop web, 1440 wide, dark mode. Work in your own new Figma file — this file is read-only reference.

How to work

1. Build exactly the 1 frame below, named exactly as listed. It is a single page (the navigation scrolls to sections), so there is no prototype to wire.
2. Everything in “Must include” must appear on that frame. The lists are grouped by subject and sorted alphabetically — they are not in page order and say nothing about layout, grouping, emphasis or styling. Those are your decisions.
3. The two brand accents and the typeface in 01 · Foundations are fixed. Define every other color yourself, plus type scale, spacing, radii, elevation and the page grid, and apply them consistently.
4. 02 · Components gives only a default Button. Design all other states, the header, the footer, the navigation and every business component as reusable components in your file.
5. Use the signature logo, the avatar, the project images, the tech and social logos and the icons from 04 · Media.
6. Copy and data must match “Fixed data” exactly. This brief wins over anything you may know of the original kit.

Frame names are fixed. Must-include lists are grouped by subject and sorted A–Z: they state what is on the screen, never where it goes or how it looks.
